# 🚀 Apache Spark (PySpark) Lab

This repository contains PySpark programs and solutions demonstrating the core concepts of Apache Spark, including DataFrame operations, Spark architecture, file handling, and optimization techniques.

## 📌 Project Overview

The project covers practical implementations of Spark concepts through hands-on exercises, including:

- Spark Architecture (Driver, Cluster Manager, Executor)
- Lazy Evaluation and DAG
- CSV & Parquet File Processing
- DataFrame Transformations and Actions
- Filtering and Selecting Data
- Column Renaming and Type Casting
- Creating Derived Columns
- Predicate Pushdown
- Fault Tolerance using Lineage Graph
- Client Mode vs Cluster Mode
- Performance comparison of `.show()` and `.collect()`

## 🛠️ Tech Stack

- Python 3
- Apache Spark (PySpark)
- Jupyter Notebook
- CSV
- Parquet


## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/your-username/your-repository.git
cd your-repository
```

Install PySpark:

```bash
pip install pyspark
```

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Open `pyspark.ipynb` and execute the notebook.
