# Customer Sales Insights using SQL

## Project Overview
This project analyzes the Superstore dataset using MySQL. The objective is to perform business analysis by applying SQL concepts such as Subqueries, Common Table Expressions (CTEs), Window Functions, and JOIN operations.

## Objectives
- Import the Superstore dataset into MySQL.
- Create Customers, Orders, and Products tables.
- Analyze sales data using SQL.
- Apply Subqueries, CTEs, Window Functions, and JOINs.
- Solve business-related SQL queries.

## Tools Used

## Business Queries Solved
- Find orders with sales greater than the average sales.
- Find the highest sales order for each customer.
- Calculate total sales for each customer.
- Find customers whose total sales are above average.
- Rank customers based on total sales.
- Assign row numbers to each order within a customer.
- Display the top 3 customers based on total sales.
- Identify the top 5 and bottom 5 customers.
- Find customers who made only one order.
- Find the highest order value per customer.

## Results
- Successfully imported the Superstore dataset into MySQL.
- Created separate Customers, Orders, and Products tables.
- Performed business analysis using SQL queries.
- Applied Subqueries, CTEs, Window Functions, and JOINs to generate customer sales insights.
