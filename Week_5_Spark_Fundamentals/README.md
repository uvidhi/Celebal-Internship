# Week 5: Spark Data Cleaning, Transformation and Aggregation

## Overview

This project demonstrates the fundamentals of **Apache Spark and PySpark DataFrames** through data cleaning, transformation, filtering, schema modification, and aggregation operations.

The project uses the **Sample Superstore dataset** and covers the questions and practical tasks provided as part of the Week 5 Spark assignment.

## Topics Covered

* Limitations of traditional Hadoop MapReduce
* Spark In-Memory Computing
* Spark DataFrames and immutability
* Removing duplicate records
* Handling null values
* Filtering data
* Grouping and aggregation
* `count()`, `sum()`, `avg()`, `min()`, and `max()`
* Schema modification and type casting
* Wide transformations and shuffle operations
* Handling inconsistent data
* Complete data processing pipeline

## Dataset

The **Sample Superstore dataset** is used for demonstrating Spark DataFrame operations.

The dataset contains sales-related information such as:

* Order ID
* Order Date
* Customer ID
* Customer Name
* City
* Region
* Category
* Sales
* Quantity
* Discount
* Profit
